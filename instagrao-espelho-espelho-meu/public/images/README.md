# Imagens do projeto

Todas as imagens são **ilustrações SVG originais**, geradas por código em [`scripts/gerar_imagens.py`](../../scripts/gerar_imagens.py). Como as pessoas do feed não existem, não há fotos de pessoas reais.

- `avatars/`: um avatar para cada pessoa (`cida`, `rafa`, `lia`, `joaquim`, `maya`, `tiago`, `bia`) e o espelho (`eu.svg`), que é o usuário logado.
- `posts/`: o que cada pessoa mais quer ver (`biblioteca`, `pantanal`, `via-lactea`, `rio`, `coral`, `pracinha`, `formatura`).

Para trocar uma imagem, coloque o arquivo aqui e ajuste o caminho e o texto alternativo (`alt`) em `src/data/posts.json`. Fotos `.jpg` e `.png` também funcionam.
